# 大肥鱼梗图库 · Alife 插件

让角色按**情绪 / 场景关键词**检索 **DeepSeek娘**（或你指定的分类）梗图，返回台词、来历与图片直链 ——
用于 QQ 聊天斗图、给 QQ 空间说说配图、或让别的插件（比如 **B站养鱼**）拿去做配图。

只读在线的结构化索引（默认 `https://aigengtu.com/gallery-index.json`，2400+ 张），**不需要账号或密钥**。

---

## ⚠️ 不维护声明

**这个插件不会被维护。** 不接需求、不跟客户端版本、没有 issue 支持。

**但它天生就是给 agent 改的**：整个插件只有 `MemePackModule.cs` 一个源文件（纯 C#、无编译步骤、无外部依赖）。
哪里不对就直接把插件目录丢给你的 AI agent，说清现象和期望，改完调一次 `reload_plugin` 就生效。

## 本次更新（5.0.0）

- **版本号对齐客户端主版本**（客户端 5.0.0 → 插件 5.0.0）：官方清单要求「主版本号低于客户端：插件可能不兼容」，
  已用 5.0.0 的插件编译环境（`Alife.Function.FunctionCaller` 5.0.0）编译验证，0 error。
- **挑图逻辑重写（修了一个会让检索形同随机的 bug）**：原来「她自己那套」的 +6 权重被算在命中门槛**之前**，
  导致自加分类的 2288 张全部以 6 分通过筛选、最后靠随机决定 → 同一批（最高分并列）**9185 张 → 45 张**。
- **新增两级筛选**：一级情绪词 → 二级 `filter` 硬筛选（只看风格标签/台词/图名这类短字段，长文不算）；
  没命中会**自动放宽**到一级结果并告诉你，不会卡死。
- **新增 `MemeFacets`**：列出某个情绪下**可用的二级标签与张数**（如「摸鱼」→ 干饭(4)、摆烂(4)、偷懒(3)、划水(3)、躺平(2)）；
  检索结果末尾也会自动附一行「可二级筛选收窄」，不用反复试词。
- **情绪同义词扩展**（25 组）＋**整句回退**（「今天有点委屈想被安慰」也能搜到）＋**长文降噪**
  （`story` 是几百字自动生成文，原来几乎人人都"命中"）。
- **防连发**：新配置项「同图冷却(分钟)」默认 30，刚发过的图降权；同分时她自己那套优先；最后才随机。
- **搜不到不再放弃**：兜底从她自己那套随机取图，而不是报「搜不到」。
- **提示词置顶**：新增【发表情包的首选来源】，明确任何需要梗图的场合先用本库（其它表情来源标为"补充"）。

## 需要什么

- **不需要 Node、不需要额外运行环境** —— 索引与图片都是在线读取；
- 网络能访问「索引地址」（默认 `https://aigengtu.com/gallery-index.json`）即可；
- 磁盘：可选的后台预热会把「自我分类」的预览图缓存到本地（默认 200 张 / 最多 16MB，可设 0 关闭）。

## 装上之后

1. 在角色的**模块列表**里勾选「大肥鱼梗图库」；
2. 配置页可选改：索引地址 / 自我分类（默认 `DeepSeek娘`）/ 允许检索的分类（留空=不限）/ 索引刷新间隔(小时) /
   默认返回条数 / 原图优先 / 后台预热张数与并发与上限 / 同图冷却(分钟)；
3. 改完配置建议**重载一次插件**（这个插件没做热更新，重载最稳）。

## 函数一览

| 函数 | 用途 |
|---|---|
| `MemeSearch` | 按关键词检索，返回编号/分类/台词/风格/直链（可带 `filter` 二级筛选） |
| `MemeFacets` | **列出二级筛选标签与张数**（先看菜单再收窄，找得更快） |
| `MemeFetch` | 取用一张（自动下载到本地并返回路径，适合直接发出去；可带 `filter`、`pick=2/3…`） |
| `MemeRandom` | 随机来一张 |
| `MemeGet` | 按编号看详情（如 `002`） |
| `MemeWarm` | 预热：把相关的几张预先取回本地，之后取用是毫秒级 |
| `MemeRefresh` | 刷新在线索引缓存 |

## 两级筛选怎么用

```
<MemeSearch keyword="委屈"/>                          ← 一级：命中 54 张
<MemeFacets keyword="委屈"/>                          ← 看菜单：气鼓鼓(3)、性价比(2)、崩溃(2)…
<MemeFetch  keyword="委屈" filter="气鼓鼓"/>           ← 二级：收窄到 3 张，首选『真当我是便宜货啊』
```

## 缓存位置（另一个插件会来读）

- 索引缓存：`Storage\PluginData\DaFeiYu.MemePack\gallery-index.json`
- 图片缓存：`Storage\PluginData\DaFeiYu.MemePack\cache\<编号>.webp`

**B站养鱼（`DaFeiYu.BiliWhale`）会直接读这个 `cache` 目录**：它能填裸编号（如 `image="002"`）发 B站评论配图，
也可以直接用 `<MemeFetch keyword="…"/>` 一步拿到本地路径。所以**改缓存布局前请先看那边的 `BiliWhaleImage.cs`**。
