# 大肥鱼梗图库 · Alife 插件

让角色在线检索 **DeepSeek娘**（或你指定的分类）梗图，返回**台词、来历与图片直链** —— 用于 QQ 聊天斗图，或给 QQ 空间说说配图。

插件**不镜像、不缓存图片本体**，只读在线的结构化索引，所以体积很小。

---

## ⚠️ 不维护声明

**这个插件不会被维护。** 不接需求、不跟客户端版本、没有 issue 支持。

**但它天生就是给 agent 改的**：整个插件只有 `MemePackModule.cs` 一个源文件（纯 C#、无编译步骤、无外部依赖）。哪里不对就直接把插件目录丢给你的 AI agent，说清现象和期望，改完调一次 `reload_plugin` 就生效。

---

## 需要什么

- **不需要 Node、不需要额外运行环境** —— 索引与图片都是在线读取；
- 只需要网络能访问「索引地址」（默认 `https://aigengtu.com/gallery-index.json`）；
- 不需要任何账号或密钥。

## 装上之后

1. 在角色的**模块列表**里勾选「大肥鱼梗图库」；
2. 配置页可选改：索引地址 / 自我分类（默认 `DeepSeek娘`）/ 允许检索的分类（留空=不限）/ 索引刷新间隔(小时) / 默认返回条数 / 原图优先；
3. **改完配置建议重载一次插件**（这个插件没做热更新，重载最稳）。

## 函数一览

| 函数 | 用途 |
|---|---|
| `MemeSearch` | 按关键词检索梗图 |
| `MemeFetch` | 按情绪 / 场景取用（返回台词、来历、直链） |
| `MemeRandom` | 随机来一张 |
| `MemeGet` | 按编号取指定那张（如 `002`） |
| `MemeRefresh` | 刷新在线索引缓存 |
